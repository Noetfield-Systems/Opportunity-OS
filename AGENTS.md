# Opportunity OS execution contract

This repository is a thin independent **UI and orchestration gateway** over the canonical Noetfield Connect Platform. Never introduce a second lead/CRM database, agent scheduler, Company OS authority registry, or auto-send workflow. Preserve explicit venture/legal boundaries, protect client PII, and link all evidence to source intake IDs. A person can submit several opportunities, roles and offers. A matching proposal never means accepted, an invitation prepared is not sent, and promises or pipeline amounts are not receipts for collected funds. Human/AI work requires scoped and auditable authorization; no unauthorized LinkedIn scraping or mass messaging. Use deterministic source-backed data, real GitHub/Railway CI and deployment receipts. Prefer revenue opportunities but never fabricate signed contracts or cash. No credential committed to Git; operator platform key stays in-memory only.
